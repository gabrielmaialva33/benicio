# Arquivo geral demonstrativo

> Fixture sintética para o gerenciador de arquivos do Benício.

Este placeholder representa anexos auxiliares do cenário jurídico legado — contratos, petições,
planilhas, imagens, correspondências e certidões. O nome e a categoria exibidos na aplicação vêm
do registro de cada arquivo; nenhum conteúdo real de cliente é armazenado aqui.
